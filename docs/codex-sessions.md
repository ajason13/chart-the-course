# Codex sessions

Open this repository as the Codex working directory, then run `codex` or create
a desktop chat for the folder. State one change and its acceptance criteria.
Repository `AGENTS.md` supplies product constraints and the declared Node
environment; `CONTRIBUTING.md` supplies verification commands.

The shared operator guide is maintained in the `terminal-dotfiles` repository
at `docs/codex-workflow.md`. In the current sibling-checkout layout, open
`../dotfiles/docs/codex-workflow.md` from this repository root. It covers
resuming sessions, local checkpoints, usage resets, the budget runner,
Dependabot, PR delivery, and troubleshooting. It is human reference material,
not required context for every agent task.
